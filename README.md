# Oculus Go Air Mouse

使用 Oculus Go 控制器操作 Windows 桌面的 .NET 10 WPF 应用。使用 WPF 内置 Fluent 主题，跟随系统明暗模式；通过 CommunityToolkit.Mvvm 8.4.2 实现 MVVM。

## 构建与启动

需要 Windows 10 2004 或更高版本、蓝牙适配器以及 .NET 10 SDK。用 Visual Studio 打开 `OculusGoAirMouse.slnx`，或运行：

```powershell
dotnet build OculusGoAirMouse.slnx
dotnet run --project OculusGoAirMouse.csproj
```

调试程序位于 `bin/Debug/net10.0-windows10.0.19041.0/OculusGoAirMouse.exe`。

## 使用

1. 在 Windows 蓝牙设置中配对控制器，并关闭其他电脑上的控制器程序，避免同时连接。
2. 按 Trigger 唤醒后点击“搜索并连接”。连接阶段和等待时间显示在主界面，可随时取消。
3. 默认不自动校准。点击“重新校准”或长按 Oculus 1 秒，也可不校准，直接点击“开启鼠标”。
4. Oculus 回主屏中央；Trigger 为左键并支持拖拽；Back 为右键；触摸板支持水平、垂直整格滚动。
5. 在“设置”页修改参数后选择“保存并应用”。数值校验通过才保存；保存后暂停鼠标；自动校准关闭时等待手动校准，开启时自动重新校准。蓝牙名称和超时设置在下次连接时使用。

默认参数：水平/垂直灵敏度 1.75/1.25，死区 65，轴映射 0/2，水平光标反转，光标平滑 0.8，最大位移 100，校准时长 1.25 秒，按键超时 3 秒，滚动阈值 30，水平滚动反转。

## 项目结构

```text
Models/       参数模型及校验
ViewModels/   主界面状态、异步命令、设置草稿与保存
Services/     蓝牙会话、输入线程、鼠标输出、配置读写、界面调度适配
tests/        无需控制器的回归检查与 ViewModel 测试
App.xaml.cs   应用组装入口
MainWindow.*  XAML 绑定及窗口句柄、DPI、关闭与滚动等视图工作
```

`MainViewModel` 和 `SettingsViewModel` 使用 Toolkit 的 `ObservableObject`、`ObservableProperty` 和 `RelayCommand`。按钮通过 XAML Command 绑定，设置字段通过 ItemsControl/DataTemplate 双向绑定。ViewModel 依赖可替换的运行时、配置存储和界面调度接口，不直接访问窗口控件或 Windows 蓝牙 API。

控制器处理和鼠标输出在独立线程串行执行，界面定时读取状态快照。断线/超时/退出会释放按键。本程序标题栏使用系统按钮区域快照及异步窗口命令处理控制器点击，保留最大化、最小化兼容修复。

蓝牙会话显式启用 `GattSession.MaintainConnection`。短暂链路中断时立即停止鼠标，保留会话等待 3 秒；期间恢复则重新校准，需手动开启鼠标；持续中断才清理会话。主动断开和退出会释放会话，不后台无限重连。

## 配置与诊断

默认配置：`settings.default.json`。个人配置：`%LOCALAPPDATA%/OculusGoAirMouse/settings.json`。升级和重构沿用原有个人配置。

配置损坏时显示错误并暂用默认值，不在加载失败时覆盖原文件。保存使用临时文件替换。诊断记录：`%LOCALAPPDATA%/OculusGoAirMouse/input-diagnostics.log`，每次启动重建，记录链路和输入处理状态。

## 重新校准与 Oculus 按钮（0.3.2）

点击“重新校准”保留当前鼠标开关。校准期间暂停光标移动和鼠标按键输出，释放正在模拟按下的按键；校准完成后，原先开启的鼠标自动继续控制，原先关闭的保持关闭。期间可手动关闭鼠标，校准结束不会重新开启。新连接、掉线恢复、应用设置时仍默认关闭鼠标。

Oculus 按下时立即居中一次；持续按住达到 1 秒自动重新校准，无需松开。长按因此会先居中再校准，持续按住不会重复触发，松开不执行额外动作。请在长按后保持控制器静止。按键数据超时会取消未完成手势，避免断线后的迟到数据误触发。

## 退出清理（0.3.1）

关闭时先阻止新的控制器输入并释放模拟按键；取消并等待进行中的扫描/连接操作；移除蓝牙事件订阅，尽力关闭通知，关闭会话保持并释放 GATT 会话、服务和设备。单项原生释放失败不会跳过后续资源清理。输入线程退出后才完成运行时释放，重复退出调用会等待同一个清理任务。

界面定时器在 ViewModel 关闭时停止。应用退出时取消诊断定时器、排空日志队列并关闭文件。检查覆盖拖拽时关闭、连接中关闭、取消后重连、原生清理异常、线程终止和日志句柄释放。强制结束进程或调试器直接终止不会运行正常退出流程。

自动重连：设置页面的“蓝牙丢失后自动重连”或配置文件 `AutoReconnect`（默认 `true`）控制。确认断线后自动搜索，失败间隔 2 秒重试；重连后恢复断线前的鼠标开关状态；是否重新校准由 `AutoCalibrateOnConnect` 控制。主动断开、关闭此设置或退出程序会取消重连。初次手动连接失败不会自动重试。

校准时长：`CalibrationDurationSeconds`（默认 1.25 秒，允许 0.1–3 秒），可在设置页编辑并保存。已有配置缺少新字段时自动使用默认时长，其余设置保留；下一次保存会写入新字段。计时以连续有效陀螺仪数据为准，数据中断超过 0.25 秒会重新计时，避免使用过期数据完成校准。

校准时显示蓝色圆形进度环，围绕鼠标位置并跟随移动。进度环透明、点击穿透、不抢焦点，不出现在任务栏或 Alt-Tab 中；主窗口最小化时仍可显示。完成校准、断线或退出时隐藏/释放。使用 Windows 置顶窗口，覆盖普通应用窗口，但不能保证覆盖安全桌面、独占全屏或系统特殊显示层。

进度环的原生窗口检查：`dotnet run --project tests/OverlaySmoke/OverlaySmoke.csproj`（会短暂显示测试进度环，不连接控制器）。

连接后自动校准：`AutoCalibrateOnConnect` 默认 `false`，设置页“连接后自动校准”可开启并保存。关闭时首次连接后等待手动校准，不显示进度环；收到陀螺仪数据不会自行校准。该开关同样控制自动重连和短暂链路恢复：关闭时沿用本次运行中已完成的校准结果并恢复原鼠标开关；没有完成的校准结果时，可直接使用未校准输入或手动校准。开启时连接/重连后自动重新校准。校准结果不跨程序重启保存。

未校准也可开启鼠标：此时陀螺仪使用零偏置，移动、左右键和双轴滚动均可使用。手动校准期间暂停输入，完成后恢复原鼠标开关状态。

启动自动连接：`AutoConnectOnStartup` 默认 `true`。启动时自动搜索并连接，连接成功后自动开启鼠标；设置页“启动时自动连接并开启鼠标”可关闭并保存，下次启动生效。启动搜索失败后可手动重试；主动取消或退出不会随后自动开启鼠标。`AutoCalibrateOnConnect` 独立控制是否自动校准，校准期间暂停输入，完成后自动继续。自动重连仍恢复断线前的鼠标开关状态。

点击防抖：Trigger/Back 按下后锁定光标 `ClickPressLockMilliseconds` 毫秒，松开后锁定 `ClickReleaseLockMilliseconds` 毫秒。默认均为 100，允许 0–2000，0 关闭对应锁定。设置页可保存。只抑制陀螺仪光标移动，不延迟按键，不影响本地鼠标与滚动；持续按住超过锁定时间后仍可拖拽。锁定期间移动被丢弃并清空平滑残留；它从收到按下/松开数据时开始，不回溯或预判按下之前的移动。

连接恢复（0.4.0）：启动/手动连接最多尝试 3 次，失败后清理会话，间隔 2 秒再试。蓝牙服务访问状态、特征枚举状态和失败阶段写入诊断日志；访问检查不会绕过 Windows 权限。

电脑睡眠时释放鼠标按键并取消正在进行的连接。唤醒后等待 2 秒，若睡眠前正在连接、已连接或正在重连，且 `AutoReconnect=true`，重新搜索并连接，恢复睡眠前的鼠标开关状态；校准仍遵循 `AutoCalibrateOnConnect`。控制器休眠时可能需要按 Trigger 唤醒；电脑无法替控制器按键唤醒。主动断开、取消或退出会停止重试。电源事件处理在退出时取消订阅。

0.4.1 修复睡眠恢复：重连订阅完成前不接收控制器输入，完成后再恢复原鼠标开关。锁屏或安全桌面暂时不可输入时，仅暂停鼠标输出，保留蓝牙连接和鼠标开关；桌面恢复后丢弃旧移动和按键，先补发必要的松键，等待控制器按键松开后再接收新按键。普通桌面上持续的权限错误仍会报告故障，不绕过系统权限。

首次使用 / 换电脑（0.4.2）：先让控制器进入配对模式，在 Windows“设置 → 蓝牙和设备 → 添加设备 → 蓝牙”中完成系统配对。程序只负责连接，不自动执行系统配对。未配对时在创建 GATT 会话之前停止，显示配对指引，启动连接及自动重连均不会反复重试该错误；完成配对后手动点击“搜索并连接”。连接区域和使用说明中均提供配对步骤。异常消息为空时显示异常类型和错误码；加密不足错误显示配对提示。
